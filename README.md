# Kana

A static Japanese kana practice tool derived from Ved's MIT-licensed Kana project.

## Included practice modes

- Brute Force: structured row-by-row kana learning and review
- Free Practice: choose hiragana/katakana and specific rows
- Word Mode: hiragana and katakana word reading practice
- Numbers: basic and compound Japanese number practice
- Kana chart with pronunciation playback

## Sound on sight

Enable **Sound on sight** from the top bar or Settings. When enabled, the current prompt is pronounced automatically when it appears. The speaker control remains available for replay. Browsers may require one manual interaction before autoplay audio is allowed.

## Accessibility

Open the **Aa** control from the top bar to change:

- Theme: Light, Dark, Warm, or High contrast
- Text size: 85% to 140%
- Font: System, Verdana, Arial, Serif, Monospace, or a custom installed font name

Accessibility preferences are saved locally in the browser.

## Run

Open `index.html`, or serve the folder with any static file server. No build step is required.
